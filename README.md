# Hospital Resource Utilization & Patient Outcomes Dashboard

## Tech Stack
- Backend: Flask
- Database: MySQL
- BI Tool: Power BI
- ETL: Python (Pandas)

## Workflow
CSV / Hospital Data
→ ETL Scripts
→ MySQL Database
→ Flask APIs
→ Power BI Dashboard

## KPIs
- Average Length of Stay (ALOS)
- Bed Occupancy Rate
- Doctor Utilization
- Cost per Patient
- Readmission Rate

## Deployment
Flask app deployed locally on internal server.
